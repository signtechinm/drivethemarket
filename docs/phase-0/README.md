## Provisional MVP defaults

The discovery package uses the following working assumptions so planning can continue:

1. Staff create or import student accounts; public self-registration is deferred.
2. Payment processing does not control access in the first release.
3. Live classes continue on an external platform without direct integration.
4. An instructor records that a class was conducted; an Academic Manager completes and releases it.
5. Materials are released manually after class completion.
6. Documents may be downloadable when staff enable downloads; recorded videos are stream-only.
7. The MVP includes email and in-app notifications.
8. Progress is based on released resource activity and video consumption.
9. Attendance, assignments, quizzes, grading, and certificates are post-MVP.
10. The system is single-institution and initially English-only.

These defaults are the implementation baseline. Later material changes are evaluated through change control and may update architecture, schedule, or backlog.
