# Operations and Staff Training

## Daily operator checks

- Health endpoint and monitoring alerts
- Failed email outbox and new website enquiries
- Today's classes and classes awaiting completion
- Materials awaiting review or release
- Suspended, expired, and soon-expiring enrolments
- Authentication, permission, and release audit events

## Staff learning path

### Administrator

Create staff/student accounts, assign only necessary roles, import students, enrol batches, review reports, and investigate audit events.

### Academic manager

Create courses and syllabuses, clone them into batches, schedule classes, verify completion, approve materials, and control release/re-lock operations.

### Instructor

Work only with assigned classes, upload draft resources, submit them for review, and mark conducted classes accurately.

### Website editor

Edit approved content, distinguish drafts from published pages, use only verified testimonials, and process enquiries without exposing personal information.

### Student support

Verify account and enrolment state before troubleshooting. Never bypass release controls or share protected links. Escalate access anomalies with the user, enrolment, batch, class, and timestamp.

## Incident priorities

- **Critical:** broad unauthorized access, credential exposure, destructive loss, or unavailable core service.
- **High:** isolated access-control failure, release-control bypass, or repeated failed core workflow.
- **Normal:** content, presentation, or non-blocking workflow defect.

Critical incidents require immediate access containment, credential rotation where relevant, evidence preservation, owner notification, and a documented recovery decision.
