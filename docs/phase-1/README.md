## Prototype scenarios

Use the top experience switcher to review these connected views:

1. Public website landing page
2. Admin operations dashboard
3. Batch list and syllabus planner
4. Controlled material-release workflow
5. Student dashboard
6. Student class and video-learning view

The prototype contains representative data only. Buttons demonstrate navigation, confirmation, release, lock-state, and responsive behavior; they do not save to a database.
